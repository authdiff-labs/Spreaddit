# Roadmap

## Near Term
- Modernize Soroban SDK and frontend client dependencies
- Add wallet-based signing (Freighter) and remove manual secret key input
- Improve validation and user-facing transaction status

## Mid Term
- Integrate token transfer/payment mechanics for voting
- Add event indexing/subscription for real-time updates
- Expand automated tests (contract + frontend + integration)

## Long Term
- Moderation and spam-resistance features
- Comment threads and richer content metadata
- Deployment automation and multi-network configuration
